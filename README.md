## TASK
1. LED PATTERN
- Blinking Effect - it is triggered when the temperature reach the threshold level(will be decided)
- Chase (Triggered after pass the threshold level, will be occured for 10 seconds, then it will trigger Emergency mode) - 10 second is because the stove can be at threshold temperature for that long before damage happen to the kitchen or house
- Random Flicker (Emergency mode) - To simulate urgency, the pattern make sure user feel the urgency to turn off the stove
- Solid (Normal) - When button been pressed, the led pattern will be back to green solid.
- No colour - indicate device is not working/inactive
